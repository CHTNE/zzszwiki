# 新城校区

新城校区拥有西北（西）、东南（东）两个食堂，我们一般称为“**老食堂**”与“**新食堂**”。

两个食堂均分上下两层，并单独设有超市。目前（2026春季学期前）除用餐时间外，原则上食堂仅允许在中午11：40、下午17：10后开启收银。除上述时间外，**正常教学时间内均不允许食堂出售任何物品**。

老食堂在菜品设置与空间大小均优于新食堂。

> 历史遗留原因使新城校区**不能**外出就餐，若想单独申请外出就餐需向班主任和年级报备。

## 老食堂

老食堂较为靠近**高三教学区**与**初中部**，主要为高三及初中学生服务。但因其菜品丰富、设计合理，通常会吸引大量高一高二学生前来就餐。

## 新食堂

新食堂较为靠近**高一高二教学区**，主要为高一高二学生服务。尽管空间较小、菜品设置较少，仍有大部分高一高二同学因节省时间（尤其是购买快餐的同学）而前往新食堂就餐。

# 市中校区

市中校区允许外出就餐。
