# 社团历史

~~此前历史有待考证，暂且不写~~

电子科技社团（曾为计算机社团）长期处于“爱好者圈子”性质，此前并未大规模纳新，仅为竞赛或邀请纳新。

2024年，时任社长**熊猫头**决定将电子科技社团并入**巨山创客社团**（保留原名称），并正式扩大纳新范围、降低纳新门槛，正式开启真正意义上第一批纳新，逐渐发展壮大。

2025年，时任社长**773**与CHTNE化学社等多个社团建交，代表社团关系取得新的突破。同时创立以**呆猫bot**为代表的多个项目，进一步提高社团知名度。

2026年，社团完成第五次换届。

> 由于校区年级政策限制，电子科技社团在2024年尝试过在市中校区正式纳新。~~但被市中校区高一年级处收缴传单~~。
> 
> 后因在市中校区难以找到合适的指导老师，自此停止市中校区正式纳新，但并不反对市中校区同学参与线上活动及竞赛活动。

# 社团现状

截至2026年7月，电子科技社团共有正式成员100人。分布在市中、新城两校区及省内外各大高校（毕业生除非主动退社，不会自动退社）。

自2024-2025学年，本社在**全国青少年科技创新大赛**、**“北斗杯”全国青少年科技创新大赛**等多项省级科创类竞赛中取得优异成绩。

目前电子科技社团在枣庄三中新城校区拥有独立活动室（科技楼一楼E102）、储藏室，并设有**多台PC**、**3D打印机**、**激光切割机**、**独立服务器**等基础设施供同学使用。此外还可借用arduino开发套件及相关开发手册进行学习，也可随时使用学校机房举办活动。~~其实没必要。活动室电脑比机房电脑强多了~~

电子科技社团持续鼓励成员参加科创类竞赛，激发创新潜能。**竞赛奖项可以用于参加山东省“综合评价招生”提前批高考录取**。此外，电子科技社团与CHTNE化学社合作进行枣庄三中校园指南 Wiki 的维护，将优质服务持续输送至广大三中学子。

> 关于综合评价招生：夏季高考**提前批**招生，采用"高考成绩+学业水平测试成绩+高校考核成绩"的录取模式，其中“白名单”科创类竞赛省级竞赛二等奖（含）以上可以作为重要投档凭证，初试过审概率较大。同时也需考生分数超过**特行线**，但普遍比常规批录取分数线低数十分。

# 活动内容

- 社团活动：周常活动于每周六晚自习开放社团活动室，允许社员自由借用公共设施，进行计算机研究学习或竞赛备赛。
  
- 社团课：在学校正式开设社团课后于每周三下午第三节课在录播教室上课。主要讲解创新思维（一般4课时）与arduino开发（一般10课时以上）。

> 电子科技社团性质较为特殊，由**信息技术组**指导老师独立管理，但并不反对接受学校官方管理。因此，电子科技社团的社团课**独立开设**。不同于其他社团课，电子科技社团不因年级会议等原因停课。只要征得班主任许可，你可以上满整学期全部课时。

> 注意：不要混淆**社团**与**社团课**的概念。因学校强制选课，参加某社团并不代表能上该社团的社团课。同理，参加社团课并不代表加入该社团。
  
- 竞赛活动：社团鼓励社员积极参与科创竞赛，社员可以自由研究、设计、创作，用作品展现自己的绝佳创意。
  
- 特殊活动：社团会在节庆日长假举办各类娱乐活动，如开设游戏服务器、举办线下活动等。如2025年“社团新春会”。

# 我们想让你知道的一些事

**电子科技从来不是理科生的代名词**，只要你有强烈的兴趣并愿意为此付出努力，相信你一定可以成功。

竞赛评奖也是如此，**项目的创意程度远比专业程度重要**。生活处处有学问，某些生活中的小事或许也可以成为成功的关键。

# 招新简介

电子科技社团会随每年学校对社团招新政策不同随机纳新，一般定于十一假期前进行走班纳新，在十一假期期间进行审核。

- 正常纳新仅针对新高一，且需要**添加纳新群、填写纳新问卷**。管理组会根据问卷填写情况决定是否面试（可线上，务必留QQ号）。我们十分鼓励在纳新问卷上多多介绍自己，回答问题**务必详细**。

- 针对新高二允许特招，需有一定技术水平或对科创方面了解，且对科创方面拥有浓厚兴趣。满足此条件可以随时添加纳新群申请线上面试。

- 新高三由于学业，暂不进行纳新。
