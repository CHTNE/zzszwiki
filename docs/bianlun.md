# 社团简介

枣庄三中辩论社正式成立于2012年，曾斩获海峡两岸辩论赛亚军、山东省高中辩论赛冠军、东吴杯辩论季军等多个奖项，是一支经过岁月磨炼和时光积淀的队伍。一代又一代的枣三辩论人薪火相传，秉承“辩字双辛，辩者自清，真知灼见，越辩越明”的理念，追求独具一格的辩风，着力培养敏锐的辩证思维、清晰流利的表达能力、从容默契的团队配合，力争发出当代的青年之声。

# 组织架构
 
辩论社由校队和社团两部分共同组成，社团举行的各类活动、比赛、模辩均面向全体成员，而寒暑假选拔出的校队成员将会参与市级、省级及全国性质的各类比赛，代表学校夺得荣誉。社团设立社长1名，副社长若干，聘请学校相关老师作为指导老师，指导社团开展工作。
