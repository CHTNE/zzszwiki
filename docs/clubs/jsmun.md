# 社团简介
巨山模拟联合国社团是枣庄三中新城校区的学生社团之一，创建于2018年。

自创建以来，本着严肃活泼，学术至上的理念，在校举办了数届模拟联合国大会，学术沙龙等活动，其学术性和趣味性兼顾的特点吸引了校内学生踊跃参加，通过模拟联合国及其他多边外交机制，围绕全球治理热点议题展开磋商、辩论与文件写作，锻炼了学生的批判性思维、公众演讲、公文写作与团队协作能力，培养具有国际竞争力的拔尖创新人才，推动素质教育向更高层次发展。 

# 社团现状
在学校支持，指导老师和历届成员的共同努力下，社团已经成长为一个具有广泛学生基础和成熟组织能力的学生团体，能够定期举办大型活动。

一年一度的巨山模拟联合国寒假峰会是枣庄三中新城校区学生进行学术交流，提示综合素养的重要平台。其承办的“辰岳模拟联合国大会”吸引了包括枣庄三中，枣庄十六中，滕州一中，枣庄八中等市内知名高中学子积极参与。 

# 活动性质

以高度模拟联合国及其他多边外交机制，依据其运作方式和议事原则，围绕国际上的热点问题展开的仿真学术模拟。

学生将扮演不同国家外交代表，遵循国际议事规则，围绕全球治理热点议题展开磋商、辩论与文件写作。

作为集语言表达、逻辑思辨、国际关系与时政分析于一体的跨学科实践课，活动旨在通过沉浸式体验，让青少年在“扮演”中学习，在“博弈”中成长，深刻理解中国特色大国外交理念与人类命运共同体内涵。
