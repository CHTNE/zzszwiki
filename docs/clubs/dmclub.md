# 社团简介
月樱动漫社是枣庄三中**新城校区**的官方社团，本社并不拒绝东校（老城校区）同学的加入。由于社团性质特殊，动漫社在校内**没有设立社团课**，社团活动以线上交流和假期的线下校外活动为主。

# 社团历史及现状
月樱动漫社作为社团中的老资历，见证了一代又一代三中学子的成长。

2023年，由于社团性质造成的校内活动的限制，月樱动漫社开始向“平台式社团”转型，并于2024年正式实现平台化，在一定程度上缓解了社团“活动荒”的问题。同时不断扩大规模，旨在做大做强。

然而，活跃新人少的问题依然没有好转，再加上2025年校方没有组织社团摆摊让这一问题更加紧迫，目前动漫社的发展面临着严峻的考验，可以说来到了社团史上最困难的时期。

> 所谓“平台化”，即将动漫社由社团组织转型为校内同好平台，社团本身仍担任组织大型活动任务，但主要是为社员构建一个舒适的交流环境。

# 社团活动
目前为止社团举办过的活动有：
茶话会、共享位置躲猫猫（新城场在凤鸣湖、老城场在东湖）、线下牌会、K歌（线上线下都有）、共游漫展等。

# 入社建议
如果你想要体验三中独特的社团风趣，却又不想整日因社团而忙碌奔波，动漫社无疑是你的最佳归宿。

虽说它不能像其它社团那样给你一场轰轰烈烈的社团活动，但却不乏可以与你谈笑风生的同行者。我们不只聊动漫，你可以谈谈你身边的日常琐事，可以谈谈你的人生理想。烦心事可以吐槽，开心事可以分享。无聊时可以水群冒泡，忙碌时也可将它暂时搁下。动漫社不会主动干涉你的高中生活，只需要你在需要时停下来坐坐就好。
