# 社团简介
术力口社为非官方兴趣社团，在两校区均有活动。社团虽起步时日尚浅、资历尚浅，却愿长久相伴，见证一届届三中学子奔赴成长之路。

# 社团历史及现状
2025年8月5日12:59，社长（QQ：1955746059）留意到校内已有东方Project相关社团，却缺少专属术曲交流社群。

东方文化与术力口同为二次元两大特色亚文化，出于这份遗憾与热爱，社长当即组建社群，术力口社就此火速诞生。

社团创立初衷十分简单：为校内喜爱术曲的同好打造一处专属交流小天地。起初本就定位为爱爱好者圈地自萌的小众社群，并未谋求官方社团编制；后续曾尝试参照象棋社申报转正，遗憾未能通过审核。

没能让三中大人尽兴，真是抱歉啊（划去）如今社团依旧以自由小众兴趣群的形式稳步运营，自在随性，初心不改。

# 社团活动
每年8月5日固定举办社团周年庆活动，届时大家一同聚会桌游比拼、线下切磋音游、共创原创企划、交换周边谷子，氛围感十足。

除却固定周年活动，平日里也会不定时组织线下小聚；线上社群氛围轻松日常，例行每周推送优质术曲推荐，闲暇时可以体验群内趣味机器人、闲聊唠嗑、打理QQ农场小游戏，随性自在。

# 入社建议
想要感受三中特色社团氛围，又不愿被繁重社团事务束缚自身学业与课余生活，术力口社便是绝佳选择。

我们绝不会随意打扰、干涉每位社员的高中日常安排。兴致盎然时，来群里听歌聊天、参与活动即可；学业繁忙无暇顾及，暂时搁置社群也完全无妨。

这里永远为热爱术力口的你留好位置，静待每一位新伙伴到来。
