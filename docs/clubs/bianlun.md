# 社团简介

枣庄三中辩论社正式成立于2012年，曾斩获海峡两岸辩论赛亚军、山东省高中辩论赛冠军、东吴杯辩论季军等多个奖项，是一支经过岁月磨炼和时光积淀的队伍。一代又一代的枣三辩论人薪火相传，秉承“辩字双辛，辩者自清，真知灼见，越辩越明”的理念，追求独具一格的辩风，着力培养敏锐的辩证思维、清晰流利的表达能力、从容默契的团队配合，力争发出当代的青年之声。

# 组织架构
 
辩论社由校队和社团两部分共同组成，社团举行的各类活动、比赛、模辩均面向全体成员，而寒暑假选拔出的校队成员将会参与市级、省级及全国性质的各类比赛，代表学校夺得荣誉。社团设立社长1名，副社长若干，聘请学校相关老师作为指导老师，指导社团开展工作。

# 活动内容

辩论社作为学校正式社团，除学校社团课外，将在休息日线上或线下举办社内及队内模辩（模拟辩论赛）以及正赛选拔赛，作为正式比赛的选拔考量。不定期举办与枣庄八中等外校联谊赛，也将代表学校参加诸如枣庄市市赛、山东省省赛、云游杯、新国辩等大型比赛。

# 入社流程

每年九月，辩论社会面向全体新生开展纳新活动。新生需线上或书面填写并提交辩论社发放的笔试单，经社团干部审核。每年九月，学校团委还会组织举办新生杯辩论赛，将比赛表现也纳入进社的考量标准之中（若未参加也不必担心，具体面试情况将作为纳新第一考量）。待到参与正式面试（考察基础思辨能力和表达能力）后，经过笔试、面试、新生杯三轮纳新的综合考察，最终确定入社名单。
